# Base de Données Locale

Une application web permettant de gérer une base de données locale avec le localStorage.

## Fonctionnalités

- Création de tables dynamiques
- Ajout de champs personnalisés (texte, nombre, date, email)
- CRUD complet sur chaque table
- Recherche en temps réel
- Persistance des données

## Installation

1. Cloner le projet
2. Ouvrir index.html dans un navigateur
   
## Utilisation

1. Créer une nouvelle table
2. Ajouter des champs à la table
3. Sélectionner la table pour voir le formulaire
4. Ajouter/modifier/supprimer des données
